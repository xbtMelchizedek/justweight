# Security

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button on this repository (Security tab → Advisories). Do not open a public issue.

In scope: anything that makes justweight show a wrong price as right, follow a non-allowlisted URL, call a paid API, spend more than its caps, write receipts with a weaker mode than 600, or execute instructions from fetched content.

justweight holds no keys and never signs, so there are no funds at risk in this code. Reports are still welcome and will be answered.
